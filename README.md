# ML Assignment 2 — Bank Marketing Classification

Streamlit application for the Bank Marketing classification assignment.

## Models
- Logistic Regression
- Decision Tree
- kNN
- Gaussian Naive Bayes
- Random Forest (Ensemble)

The five models are custom implementations. OneHotEncoder and StandardScaler are used for preprocessing.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

Upload `test_data.csv`, select a model, and view predictions and evaluation metrics.
